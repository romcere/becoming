# 未竟 / Becoming

> Becoming who you want to be.

一个基于 uni-app + Vue3 + TypeScript 开发的个人成长管理应用。

## ✨ 项目简介

「未竟（Becoming）」是一款围绕：

- 习惯养成
- 打卡记录
- 积分激励
- 记账管理
- 奖励兑换

构建的长期成长型应用。

它并不强调“完成”。

而是强调：

> 持续成为更好的自己。

---

## 🧩 组件库

**[wot-ui v2](https://wot-ui.cn/)**

轻量、美观、AI 友好的 `uni-app` 组件库。

特点：

- 支持 Vue3
- 适配多端
- 风格统一
- 上手简单
- 更适合现代化移动应用开发
